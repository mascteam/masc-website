# Club Website

A full-stack club management and public-facing platform for managing **blogs, events, users, attendance, registrations, and event engagement**.

The project is split into two independent applications:

```text
.
├── client/     # Next.js frontend
│   └── README.md
│
└── server/     # Express backend
    └── README.md
```

## Project Structure

| Directory           | Description                     |
| ------------------- | ------------------------------- |
| [/client](./client) | Next.js 16 frontend application |
| [/server](./server) | Express 5 backend API           |

## Getting Started

Clone the repository:

```bash
git clone https://github.com/mascteam/masc-website.git
cd masc-website
```

### Client Setup

```bash
cd client
bun install
bun dev
```

See [client/README.md](./client/README.md) for frontend setup, routes, architecture, and environment variables.

### Server Setup

```bash
cd server
bun install
bun run dev
```

See [server/README.md](./server/README.md) for backend setup, API architecture, environment variables, and deployment information.
